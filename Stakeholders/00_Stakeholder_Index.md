# PRISM - Stakeholder Mapping

This is an interactive knowledge graph of key stakeholders in AI consciousness and digital minds research.

## How to Use This Knowledge Graph
- Each stakeholder has their own page with detailed information
- The graph view shows connections between stakeholders
- Tags are used to categorize stakeholders by research area, institution, etc.
- Click on any link to navigate to that stakeholder's page
